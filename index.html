The page loaded but the game did not start. This host is serving the repository source rather than a built site.

On GitHub Pages, this means the source is set to Deploy from a branch. That publishes your files through Jekyll, which cannot build this app — and it overwrites the real build on every push. Go to Settings → Pages → Source and choose GitHub Actions. The workflow in .github/workflows/deploy.yml then does the build.

Anywhere else, run npm install && npm run build and serve the dist/ folder.
